Introduction

TryMyWatch is an Augmented Reality web application that allows users to virtually try on watches in real-time using their camera. It delivers an immersive and interactive experience, helping users visualize how a watch looks on their wrist before making a purchase decision.

Project Objectives

  • Provide a realistic AR watch try-on experience in real-time.
  • Allow users to explore a wide range of watches virtually.
  • Enhance user engagement and purchase confidence.
  • Build a scalable and efficient web platform.

Technologies

  • Backend: Laravel (PHP)
  • Database: MySQL
  • Frontend: HTML5, CSS3, JavaScript
  • AR/3D: WebXR, Three.js
  • Others: REST API, Eloquent ORM, Blade Templating

Methodology

  • Requirement Analysis
  • System Design
  • 3D Model Integration
  • AR Implementation (WebXR)
  • Backend Development (Laravel)
  • Testing & Optimization
  • Deployment
